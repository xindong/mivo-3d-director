# Mivo 3D 导演台

浏览器里就能用的 3D 分镜导演台：摆角色、摆机位、铺全景背景、按镜头记录截图。技术上是 React + Vite + Three.js（React Three Fiber）。

**在线地址（内网）**：https://mivo-3d-director-app.workers.xd.team

> 本项目 fork 自 **[jiguang132/storyai-3d-director-desk](https://github.com/jiguang132/storyai-3d-director-desk)**，原作者把底座打得相当完整（角色系统、群众阵列、多格式模型导入、机位与截图、撤销剪贴板等等）。我们在它的基础上重做了界面、收拾了一批交互细节、解决了拖动卡顿，并接上了 Mivo 的素材库。原项目的功能说明可以直接看上游 README。

## 我们做了什么

### 一、界面：照着 Mivo 的设计语言重做了一遍

原来是"能用但不成体系"的界面，现在统一到 Mivo 那一套暗色语言：

- **主题色**：全站主色改成 Mivo 的紫 `#745ef5`（原来是蓝色）。按钮、开关、滑块、选中态、焦点光圈全部跟着走。
- **颜色和描边**：面板底色 `#1a1a1a`、边框统一成"白色 10%"的细边、次要文字用 `#99999f`；窗体和面板不再是一堆不同的灰。
- **圆角与字号**：控件统一 8px 圆角，面板 16px；一级标题 14px/500 白字、二级标题 14px/500 白色 40%、说明文字 12px/400，整套层级只有这三档，不再出现"12px 灰字和 14px 白字混着用"。
- **顶部标签页**：右侧面板的 3D场景 / 全景 / 地面 / 其他，改成和面板融为一体的通栏标签（贴着面板边缘、无内边距、底部分隔线），选中项是**实心主题色 + 白色加粗文字**，滚动内容时标签固定不动。
- **控件重做**：
  - 输入框、数字框：40px 高、14px 字，悬停变紫边、聚焦带一圈淡紫光圈；
  - 数字框右侧补了上下步进箭头（悬停才出现，点一下按步长加减）；
  - 下拉框整体放大（触发器 40px、选项行 40px、弹层实心底 + 选中项紫字 + 浅底），不再"小家子气"；
  - 滑块：8px 轨道、**已经走过的部分填充主题紫**、白色圆形手柄，聚焦时手柄有一圈紫色光晕；
  - 开关：一行一个，右侧是胶囊开关（"开启 / 关闭"文字 + 滑块），文字点击不会误触发；胶囊整体缩小到 50×22，和滑块行同一个体量。
- **左侧对象列表**：每个节点右侧补齐"可见性 / 锁定 / 删除"三个按钮（间距收紧），并去掉了搜索框里那个多余的放大镜图标；列表在拖对象时不再整棵重渲染。
- **其他**：重置视角按钮（右上角坐标轴下方）、错误界面、空状态提示、面板内的分段选择卡（全景图/背景图）都统一成同一套观感。

### 二、交互：少点几下，少踩几个坑

- **场景面板拆成四个 tab**：场景（平移/旋转/缩放）、全景（天空颜色、全景图、显示方式与参数）、地面（开关 + 透明度/高度）、其他（角色标签、显示网格）。**天空颜色放在了全景 tab 最上面**。
- **全景图二选一**：可以当**全景图**（等距柱状投影，随相机转动，能调水平旋转和半径），也可以当**背景图**（一块始终正对相机的背景板，不随相机移动产生视差，能调缩放和上下左右位置）。普通照片自动按背景图处理。
- **全景图入口直白**：空着的时候卡片上写着"从 Mivo 选择 / 从本地选择"，前后都是纯文字（hover 变紫），不再弹一层菜单；已经上传了图，点图片会浮出一个纵向小菜单（从 Mivo 选择 / 从本地选择），选完就是替换。删除按钮还是右上角那个小垃圾桶。
- **相机截图更好用**：截图列表改成两列网格；预览从"挤在右侧面板里的一条"改成**全屏弹窗**（放大/缩小/下载/关闭），缩略图上的按钮改成"删除 / 下载 / 查看"；点底部的"当前视角截图"会**自动切到对应机位、并停在摄像机截图 tab**。
- **导入模型**：底部按钮从"导入本地模型"改名"导入模型"，点开是上拉菜单（从 Mivo 选择 / 从本地选择），菜单跟着按钮弹出、文字居中对齐。
- **滑块范围与步长**：所有 X/Y/Z 轴滑块统一 **-50 ~ 50、步长 0.1**；数字框支持先敲负号（以前打"-"会立刻被吞成 0）、支持方向键和步进箭头。
- **显示网格**：开关终于真的管用了（以前代码里写死一直显示），默认开启，关掉就干净。
- **底部工具栏**：按语义分组（变换 / 添加 / 取景 / 视图）并用短竖线分隔；去掉了"导入全景图""模型库"两个重复入口；新增 **重置**（一键回到初始场景，用于存档坏了自救）和 **重置视角**（切回导演视角并恢复初始机位）。
- **视角切换按钮**：选中态改成实心主题色 + 白色加粗图标与文字。
- **轴控件统一形态**：位置/旋转/缩放这类三轴参数，统一为"一个小标题 + 三行带 X/Y/Z 标识的滑块"，不再一行行重复写"场景平移 X"。

### 三、性能：拖动不再卡顿

原来拖动模型会非常卡——根因是**每拖动一帧**都在做三件重活：把整个场景深拷贝一遍、做一次全量 JSON 比较、再把几 MB（含截图 base64）的存档**同步写进 localStorage**。

现在：

- **平时不落盘**：拖动过程中一次存储都不写，只记一个"脏"标记；退出/刷新/切到后台时才真正写一次（刷新或关闭页面会先落盘、再给一个"可能有未保存修改"的提示）。
- **拖动批处理里跳过重活**：拖动期间不再每帧做快照和深比较，只做一次不可变更新；没有实际变化时直接返回原状态，连重渲染都不触发。
- **左侧列表不再跟着抖**：列表只订阅它真正要显示的字段（名称、可见、锁定、分组、模型引用）组成的签名，拖位置时签名不变，整棵列表不重渲染。
- 效果就是：拖动从"一顿一顿"回到跟手。

### 四、稳定性：把"打不开 / 白屏"这类问题堵上

- **存档自愈**：读存档时会先做一遍体检——剔掉已经失效的本地资源（`blob:` 链接关掉页面就作废，这是"重新打开就卡住"最常见的原因）、把 `NaN` 之类的坏数值改回默认、解除指向已删除对象的引用、清掉指向不存在对象的选择状态。
- **应用级错误边界**：真遇到渲染崩溃不再白屏，会显示错误信息 + "重新加载 / 重置场景数据"两个按钮，即使工具栏点不动也能自救。
- **不再闪白**：默认主题改成暗色，并在 `index.html` 的内联脚本里**先定好主题再加载样式**，刷新时不会先闪一片白再变暗。

### 五、Mivo 素材库：直接用 Mivo 里的模型和图片

- **连接**：底部工具栏最左边是 Mivo 入口（紫色图标）。点开输入 Mivo API Key，走官方接口 `POST /api/v1/state/token` 换取 session（和官方 MCP 客户端同一套契约），之后所有请求带 `Authorization: Bearer <session>`。连接成功后按钮变紫色高亮，凭证只存在本机浏览器，随时可以断开。
- **选素材**：弹窗里有"历史创作 / 历史上传"两个来源、搜索框、缩略图网格；**模型最多一次选 10 个**，全景图**点一下就应用**。
- **落地**：选完按 `fileId` 下载真实文件，再交给现有的本地导入流程（模型走 `readLocalModelFile`、全景图走 `readPanoramaFile`），所以导入后的行为和"从本地选择"完全一致。
- **跨域怎么解决的**：Mivo 的接口不允许其它域名的网页直接调用，所以站点带了层服务端代理——浏览器只访问同源的 `/api/mivo/*`，由 Worker 转发到 `aigc.xindong.com`（服务端请求不受 CORS 限制）。缩略图这种 `<img>` 发不出请求头的场景，代理支持 `?access_token=` 并在转发时转成 `Authorization` 头。本地开发用 Vite 的同名代理，同一套契约，不用再折腾跨域。

## 功能一览

**角色与场景**

- 导演视角 / 机位视角切换，视口比例框、九宫格、平移 / 旋转 / 缩放
- 内置 8 种人物体型、20 种姿势
- 角色、群众阵列（想放多少人放多少人）、基础几何体、机位一键添加
- 对象可见性 / 锁定 / 删除，多选、复制粘贴、撤销
- 地面（开关、透明度、高度）、网格显示、场景整体缩放与位移

**全景与背景**

- 全景图（等距柱状）：天空颜色、水平旋转、半径
- 背景图：锁定相机的背景板，可调缩放与位置
- 支持从 Mivo 或本地选择，随时替换

**模型导入**

- 基于 `mivo-model-viewer` SDK：GLB / GLTF / OBJ / FBX / STL / PLY / DAE / 3MF / 3DS / ZIP（带贴图的建议打 ZIP）
- 从 Mivo 素材库选择（单次最多 10 个），或从本地选择
- 导入后进入场景并自动分散排布

**机位与截图**

- 机位切换、位置与注视坐标、视野角度（FOV）
- 当前视角截图 / 四方位 / 十二方位，截图两列网格、全屏预览、下载
- 视口画幅比例与安全框，截图按当前画幅裁切

**Mivo 集成**

- API Key 连接、凭证本机保存、随时断开
- 历史创作 / 历史上传素材浏览与搜索
- 同源 Worker 代理（`/api/mivo/*`），缩略图与文件下载都走它

## 技术栈

- React 18 + TypeScript
- Vite 6
- Three.js + @react-three/fiber + @react-three/drei
- Zustand（状态、撤销栈、剪贴板）
- `mivo-model-viewer`（模型解析与查看）
- Vitest（单元测试）
- XD Sites（内网发布：Worker with assets）

## 项目结构

```text
src
├─ app/layout          # 顶层壳：全屏画布 + 左右悬浮面板
├─ app/ErrorBoundary   # 出错兜底界面
├─ assets              # Mivo 图标等静态资源
├─ editor/canvas       # 3D 视口、坐标轴、画幅框、底部工具栏、截图
├─ editor/panels       # 左侧对象树、右侧属性面板、Mivo 连接与素材弹窗
├─ editor/mivo         # Mivo 客户端（认证 / 素材列表 / 下载）与连接状态
├─ editor/store        # Zustand 状态、撤销与剪贴板、存档读写与自愈
├─ editor/io           # 截图导出、工程导入导出、宿主通信
├─ editor/loaders      # 本地模型与全景图导入
├─ editor/runtime      # 角色渲染、骨骼与姿势
├─ editor/schema       # 数据结构、机位与视口定义
└─ styles              # 全局样式
worker
└─ index.js            # XD Sites Worker：/api/mivo/* 转发 + 静态资源
```

## 本地开发

```bash
npm install
npm run dev
```

默认地址 `http://127.0.0.1:5173/`（端口被占用时 Vite 会自动顺延）。开发服务器已经配好 `/api/mivo` 代理，所以本地也能正常连接 Mivo。

预览生产包：

```bash
npm run preview
```

## 构建与发布

**普通构建**（本地预览、或部署到根路径的站点）：

```bash
npm run build      # 产物在 dist/
```

**带代理的 Worker 站点构建**（内网站点用的就是这个）：

```bash
npm run build:site # 产出 deploy-root/（worker.js + public/ 静态产物）
```

**纯静态站点构建**（若部署到带 base 路径的静态站点，需要把 `VITE_SITE_BASE` 指过去）：

```bash
VITE_SITE_BASE=/s/<site-code>/ npm run build
```

> 两种站点的区别：纯静态站点没有服务端代码，浏览器直连 Mivo 会撞 CORS，所以只能用"本地导入"；Worker 站点带 `/api/mivo/*` 代理，Mivo 连接、素材库、缩略图、下载都能用。内网地址请用 [mivo-3d-director-app.workers.xd.team](https://mivo-3d-director-app.workers.xd.team)。

## 常用操作

- 顶部胶囊切换 `导演视角` / `机位视角`
- 左侧搜索、分组查看场景对象，行尾按钮控制可见 / 锁定 / 删除
- 中央视口摆场景，底部工具栏切换变换模式、添加角色 / 群众 / 几何体 / 机位、导入模型、调画幅、截图、重置
- 右侧属性面板随选中对象自动切换（场景 / 角色 / 模型 / 摄像机）
- 右上角坐标轴切视角方向，下面「重置视角」一键回到初始机位

## 快捷键

- `Ctrl/Cmd + C`：复制当前选中对象
- `Ctrl/Cmd + V`：粘贴复制对象
- `Ctrl/Cmd + Z`：撤销最近一次操作
- `Delete / Backspace`：删除当前选中对象

## 数据与嵌入

- 场景与本地模型库存在浏览器 `localStorage`，为了性能**只在离开页面或切到后台时统一落盘**；正常刷新会先保存再提示
- 场景数据做了自愈：失效的本地资源、坏数值、悬空引用都会被自动清理
- 支持导出工程 JSON、从文件重新导入、保存 / 恢复最近工程
- 内置宿主页面通信桥，适合嵌进更大的创作工作台
- Mivo 的 API Key 与 session 也只保存在本机浏览器
